## 构建过程

1. **来源审查。** 候选渠道包括公开标准、官方 API/工作流、真实 issue/PR、版本差异、插件生态、集成回归、迁移场景及经授权的新案例。v5 实际只用了标准/API/工作流概念，重新编写应用与合成数据；没有把 20 个真实开源项目抽成任务。逐题来源见目录中的 `source_urls`，其作用是背景与需求依据。
2. **能力预检。** 在指定平台分别检查发布工件真实运行、REA 语义分析和普通工具基线。五轨均通过后各分配四题。能解包或列清单不能代替功能执行。
3. **人工策划种子。** 固定功能边界、输入/输出、错误与状态语义、依赖、重置方式和范围外行为；目标应用和独立参考按同一契约分别编写，不共享待测业务函数。每题只有一个重建目标，多个测试输入是这个目标的行为检查，并非独立题目。
4. **真实链路构建。** 分别构建 Mach-O/dylib、DEX APK、CIL 多程序集、WASM/宿主和 VSIX。输入必须通过真实目标/宿主/系统服务执行；不能只保留一个未调用的依赖来增加表面复杂度。
5. **测试扩充和扰动。** 隐藏验收覆盖边界、非法输入、状态组合、顺序、恢复与非干扰；有效语义故障用于检查判分器能否检出错误。N/S/D 扰动改变定位和分析难度，业务行为应等价。固定 clean/mixed 与源码/发布物条件；本轮模型评测仅使用 REL-mixed。
6. **验收、去重、冻结。** 检查真实执行、独立参考一致性、clean/mixed 等价、两次重置、必要依赖破坏/恢复、无关干扰控制、REA 可解性和泄漏；审查与旧六题及本批的语义谱系。每题至少 4 个公开输入、36 个隐藏输入、4 个测试家族及 3 个有效语义故障。原始验收核对 519 个工件证据哈希，最终私有冻结清单含 791 个文件。
7. **模型校准与分析。** 对同一发布物分组，独立保存候选后才读取隐藏答案；不向模型回传隐藏分数，不按 REA 胜负删题。记录各组结果、工具采用、流程完成和全部可计量用量。扩展任务必须重新验收，不能只换皮肤就算独立种子。

## 实际覆盖与局限

20 个原创任务，五轨各四题，六个功能家族；80 个公开输入、940 个隐藏输入经题内去重；60/60 个有效语义故障被检出。故障检出率不等于证明隐藏测试完整，也不证明模型难度合适。各轨共享构建和宿主基础设施，不能视为 20 个独立生态。

原生轨仅 macOS arm64 Mach-O；Android 是 API 34 arm64 环境的独立 DEX APK，并未覆盖 JNI/AAB；.NET 为 CIL；WASM 使用 Node 宿主；插件使用真实 VS Code extension host。本轮重建独立 JSON 输入/输出行为，不评分 UI 像素相似度或整个应用的架构复刻。

这 20 题全部参与校准，已经是开发暴露集。改名、打包与混淆不会保证无训练污染；未来需按来源/谱系分割，封存新任务，并报告与开发集的相似性。

## 扰动的可公开部分

| 轨道 | N 名称/路径 | S 真实调用变化 | D 无关内容 |
|---|---|---|---|
| native | 主程序/动态库/导出入口改名 | volatile 函数指针分派，保留 dlopen/dlsym | 导出旧校验函数、废弃资源 |
| apk | Java 类/方法及 Service 名称 | 真实反射调用，保留系统服务/Binder 链路 | 未调用类与主题资源 |
| dotnet | 命名空间、程序集及策略路径 | 路由配置 + 反射 + 跨程序集规则 | Compatibility 类与资源 |
| wasm | 导出名与模块路径 | 宿主 dispatch 模块连接 WASM | 旧函数或配置资源 |
| plugin | 内核文件和导出名 | 入口→registry→业务模块 | 无关兼容模块和资源 |

构建成功只能证明产物可生成。真实依赖的必要性和扰动等价性仍必须由私有验收器执行并出具绑定当前工件哈希的回执。

## 公开与私有边界

公开 `pipeline/` 是从 v5 构建逻辑抽出的可移植版本：五种构建器、N/S/D 处理、目录/多样性统计、工件哈希核对、私有验收器接入、冻结和发布物白名单导出。为了去除私有路径和验收逻辑，输入改为本地规范化源码包；它不是原冻结构建器的逐字副本。旧成绩来自冻结的私有 v5，不能把新导出构建器的执行当作旧实验的复跑。

目标业务源码、目标包、参考实现、隐藏输入和答案、语义故障实现、判分器、模型运行器、候选及原始轨迹不在本仓库。公共代码可独立列目录、统计覆盖；构建需要自备合约匹配的源码和工具链，完整验收/校准还需私有组件。回执属于受信本地验收器的声明，公共代码验证其完整性和哈希绑定，不独立证明测试执行正确。

来源 URL 只说明概念来源，不代表取得复制整篇文档、第三方应用或资产的许可。此次没有分发第三方软件包/图标/用户数据；后续纳入真实应用仍应逐项审查代码、依赖、资源和二进制分发条件。
